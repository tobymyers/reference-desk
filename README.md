# The Scaling Reference Desk — Teams tab pages

Static personal-tab pages for the Scaling Reference Desk Teams app (Copilot Studio bot + tabs).
Source of truth lives in the Copilot Bot project (`reference-desk-tabs/`, generated from wireframe v9).
Served via GitHub Pages; embedded in Teams via staticTabs in the app manifest.

- `patterns.html` — Scaling Patterns tab (deep-link: `?sub=pattern:payer|pilot|doer|focus`)
- `cases.html` — The Cases tab: index curve + native easements case page (deep-link: `?sub=case:easements`)
